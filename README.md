# Fake Chat

AI chat for OBS. Fake viewers listen to you talk, see your screen, and type in chat like real people.

Everything runs in your browser. Your API key, OBS password, viewers and memory are saved in your own browser only. They're never stored in this repo.

## Use it

1. Open the GitHub Pages link for this repo in Chrome or Edge.
2. Pick an AI provider and paste your key.
3. Hit Start listening.
4. Follow the "Send to OBS" steps on the page.

## In OBS

Add a Browser source and use the same Pages link, 400 x 700. Inside OBS the page shows just the chat with a see-through background.
